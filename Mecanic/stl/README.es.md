# Piezas STL

[Mecánica](../README.es.md) · [Português](README.md) · [English](README.en.md)

Este directorio reúne piezas exportadas para impresión 3D.

## Ejemplos

Incluye piezas de brazo, cuerpo, cabeza, prolongadores, soporte del láser y soporte del Raspberry Pi.

## Antes de imprimir

Verifique revisión, escala, orientación, material, tolerancias y compatibilidad con tornillos, servos, placas y la versión de montaje utilizada.

Existen piezas históricas, por lo que un STL no debe asumirse automáticamente como la revisión de referencia más reciente.
