# Peças STL

[Mecânica](../README.md) · [English](README.en.md) · [Español](README.es.md)

Este diretório reúne peças exportadas para impressão 3D.

## Exemplos

O acervo inclui:

- base do braço;
- extensão de braço;
- corpo inferior e superior;
- peças da cabeça;
- prolongadores;
- suporte do laser;
- suporte do Raspberry Pi.

## Antes de imprimir

Confirme:

- revisão da peça;
- escala;
- orientação;
- material;
- tolerâncias;
- compatibilidade com parafusos, servos e placas.

Como existem peças históricas, nem todo STL corresponde necessariamente à montagem de referência mais recente.
