# Mecánica de Robotinics

[Proyecto principal](../README_ES.md) · [Português](README.md) · [English](README.en.md)

La carpeta `Mecanic` contiene la estructura física de Robotinics: modelos CAD, ensamblajes y piezas para impresión 3D.

## Estructura

### `solidwork/`

Piezas y ensamblajes SolidWorks.

### `stl/`

Archivos exportados para fabricación e impresión 3D.

## Módulo de cabeza

La cabeza soporta dos ejes con servos, el puntero láser y el sensor ultrasónico. Puede trabajar junto con una cámara procesada por Raspberry Pi.

El láser funciona como referencia visual/óptica para experimentos de percepción activa.

## Revisiones

Coexisten varias revisiones históricas. Antes de imprimir una pieza, verifique escala, fijaciones, compatibilidad con servos y versión de montaje.
