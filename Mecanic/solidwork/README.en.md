# SolidWorks Models

[Mechanics](../README.en.md) · [Português](README.md) · [Español](README.es.md)

This directory contains Robotinics CAD parts and assemblies, including body, bases, arms, laser support, Raspberry Pi support and head parts.

CAD files are the preferred source for dimensional changes. Consider electronics, servo clearance, wiring and derived STL files when modifying geometry.
