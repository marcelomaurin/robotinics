# Modelos SolidWorks

[Mecânica](../README.md) · [English](README.en.md) · [Español](README.es.md)

Este diretório contém as peças e montagens CAD do Robotinics.

## Conteúdo

Inclui a montagem geral e componentes como:

- corpo;
- bases;
- braços;
- suporte do laser;
- suporte do Raspberry Pi;
- partes da cabeça.

## Uso

Os arquivos CAD são a referência para alteração dimensional e evolução mecânica.

Antes de modificar uma peça, considere interferência com eletrônica, servos, cabeamento e peças STL derivadas.
