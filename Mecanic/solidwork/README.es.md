# Modelos SolidWorks

[Mecánica](../README.es.md) · [Português](README.md) · [English](README.en.md)

Este directorio contiene piezas y ensamblajes CAD: cuerpo, bases, brazos, soporte láser, soporte Raspberry y cabeza.

Use los archivos CAD como referencia para cambios dimensionales y revise interferencias con electrónica, servos y cableado.
