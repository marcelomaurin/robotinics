# Robotinics AI Runtime — Raspberry Pi

[Português](README.md) · [English](README.en.md)

Este módulo documenta el runtime de IA propuesto para Raspberry Pi basado en TCHATGPT.

Incluye servicios de LLM, Agente, Internet, RAG, Visión, Voz, Telemetría, Robot Gateway, Documentación y Auditoría.

Sólo RobotGateway puede comunicarse con Arduino Mega. TAIAgent utiliza herramientas y no acceso serial directo.

La información de internet es contexto externo y nunca autoriza directamente una acción física.
