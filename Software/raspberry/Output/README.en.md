# Raspberry Output

[Raspberry](../README.en.md) · [Português](README.md) · [Español](README.es.md)

This historical module contains Raspberry Pi output logic.

It should encapsulate commands and data sent to Arduino Mega, auxiliary modules, user interfaces, external services, logs and telemetry.

High-level actions should be translated into well-defined protocol messages before reaching microcontrollers.
