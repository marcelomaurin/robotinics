# Raspberry Output

[Raspberry](../README.es.md) · [Português](README.md) · [English](README.en.md)

Este módulo contiene lógica histórica de salida del Raspberry Pi.

Debe encapsular comandos enviados al Mega, módulos auxiliares, interfaces, servicios, logs y telemetría. Las acciones de alto nivel deben convertirse en mensajes de protocolo bien definidos.
