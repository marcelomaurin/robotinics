# Salida para Arduino

[Raspberry Output](../README.es.md) · [Português](README.md) · [English](README.en.md)

Este directorio contiene servicios históricos relacionados con comunicación y monitoreo de Arduino, incluyendo `srvFala/` y `srvMonitor2/`.

La comunicación serial y el protocolo deben quedar aislados de la lógica de aplicación de alto nivel.
