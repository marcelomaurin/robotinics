# Camera Module

[Raspberry](../../README.en.md) · [Português](README.md) · [Español](README.es.md)

This directory contains historical Raspberry Pi camera and vision resources.

- `motion/` contains Motion-related material;
- `opencv/` contains OpenCV-based experiments.

The camera can support environment capture, object detection, MCabeca laser-dot detection, calibration, scanning and monocular-perception experiments.

Raspberry Pi performs image processing and converts image information into physical angles. MCabeca only executes those angles.
