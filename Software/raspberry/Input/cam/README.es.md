# Módulo de Cámara

[Raspberry](../../README.es.md) · [Português](README.md) · [English](README.en.md)

Este directorio contiene recursos históricos de cámara y visión.

- `motion/` contiene material relacionado con Motion;
- `opencv/` contiene experimentos basados en OpenCV.

La cámara puede utilizarse para captura, detección de objetos, detección del punto láser, calibración, scanning y percepción monocular.

Raspberry Pi procesa la imagen y convierte la información visual en ángulos. MCabeca sólo ejecuta esos ángulos.
