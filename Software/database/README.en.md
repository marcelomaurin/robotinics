# Robotinics Database

[Main project](../../README_EN.md) · [Software](../README.en.md) · [Português](README.md) · [Español](README.es.md)

This directory contains database artifacts used by Robotinics.

Current content is organized around MySQL.

The database is a persistence layer, not a real-time motor-control layer. Appropriate data includes configuration, device metadata, events, telemetry, command history and application state.

A future version should document schema, relationships, migrations and sample data. Credentials must never be committed to the repository.
