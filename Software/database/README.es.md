# Base de Datos de Robotinics

[Proyecto principal](../../README_ES.md) · [Software](../README.es.md) · [Português](README.md) · [English](README.en.md)

Este directorio contiene artefactos de base de datos, actualmente asociados a MySQL.

La base de datos debe utilizarse para persistencia de configuración, dispositivos, eventos, telemetría e historial, no para control físico en tiempo real.

Una nueva revisión debería documentar esquema, relaciones, migraciones y datos de ejemplo. Las credenciales no deben almacenarse en el repositorio.
