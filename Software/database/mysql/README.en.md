# MySQL — Robotinics

[Database](../README.en.md) · [Português](README.md) · [Español](README.es.md)

This directory contains Robotinics MySQL assets.

MySQL is a persistence layer for configuration, device metadata, telemetry, events, command history and application state. It should not participate directly in real-time motor control.

Keep schema scripts versioned, avoid committing real credentials and document migrations and relationships.
