# MySQL — Robotinics

[Base de datos](../README.es.md) · [Português](README.md) · [English](README.en.md)

Este directorio contiene los artefactos MySQL.

MySQL debe utilizarse para configuración, dispositivos, telemetría, eventos e historial. No debe participar directamente en control físico en tiempo real.

Mantenga scripts de esquema versionados y nunca guarde credenciales reales en el repositorio.
