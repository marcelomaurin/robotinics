# Fontes das ilustrações da Rev. 3

Este arquivo registra a origem editorial das imagens incorporadas à edição em português.

## Referência fornecida pelo autor

- `componentes/shield_mega_conectores_chaveados.png`: imagem enviada por Marcelo Maurin Martins como referência visual para a substituição da shield aberta. A fotografia identifica uma categoria de produto; não garante fabricante, família de conector, passo ou pinagem do exemplar comprado.

## Acervo da edição anterior

As imagens abaixo foram extraídas de `docs/Projetos IOT com Arduino e Raspberry-rev10.pdf`, publicação anterior do próprio projeto, para restaurar a sequência didática e a identificação visual dos componentes:

- `componentes/sensor_corrente_acs712.png`;
- `componentes/driver_l298n.png`;
- `componentes/sensor_hcsr04.png`;
- `componentes/principio_ultrassom.png`;
- `componentes/ligacao_hcsr04_rev10.png`.

O arquivo `ligacao_hcsr04_rev10.png` permanece como referência de acervo e não é usado como esquema normativo. As ligações válidas estão no manuscrito e nos diagramas gerados a partir do firmware.
