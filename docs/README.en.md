# Robotinics Documentation

This folder contains historical documentation and educational material related to Robotinics.

## History and origin

Robotinics was originally presented in **2015** as a **final course project (TCC)** for the **Industrial Mechanics Technical Program** at **Etec José Martimiano da Silva**, Ribeirão Preto, São Paulo, Brazil, part of **Centro Paula Souza**.

The project was multidisciplinary from the start, combining mechanics, physical structure, electronics, sensors, actuators, microcontrollers and software. The current repository preserves material from different stages of that evolution.

Institution: [Etec José Martimiano da Silva – Centro Paula Souza](https://www.cps.sp.gov.br/etecs/etec-jose-martimiano-da-silva/)

A major resource is the **IoT Projects with Arduino and Raspberry** material stored in the repository.

Module-specific documentation is kept near each subsystem, while `docs/` should contain broader material such as architecture, assembly guides, protocol specifications, diagrams, tutorials and project history.

Primary documentation languages are Portuguese, English and Spanish.
