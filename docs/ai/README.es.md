# Robotinics AI — Continuación de Rev. 3

[Português](README.md) · [English](README.en.md)

Esta carpeta documenta la continuación de Robotinics con una capa de IA ejecutada en Raspberry Pi y basada en **TCHATGPT**.

Raspberry Pi gestiona LLM, RAG, internet, visión, voz, planificación, interpretación de telemetría y mantenimiento asistido de documentación.

El LLM nunca controla motores o servos directamente. Toda acción física pasa por validación determinística y el protocolo del Arduino Mega.

Consulte `ARCHITECTURE.md`, `INTERNET_INTEGRATION.md`, `DOCUMENTATION_AGENT.md` y `Software/raspberry/AI/README.md`.
