# Projetos EAGLE

[Eletrônica](../README.md) · [English](README.en.md) · [Español](README.es.md)

Este diretório contém projetos eletrônicos criados no Autodesk EAGLE.

## Conteúdo

Há projetos relacionados a:

- controle de servomotor;
- LEDs;
- circuito de carregamento;
- distribuição de 5 V.

## Uso

Antes de fabricar uma placa:

1. confirme a revisão;
2. verifique alimentação e corrente;
3. compare a pinagem com o firmware;
4. confira disponibilidade dos componentes;
5. revise trilhas de potência.

Os arquivos refletem diferentes momentos do projeto e devem ser validados antes de uso.
