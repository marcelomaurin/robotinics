# Arquivos PCB

[Eletrônica](../README.md) · [English](README.en.md) · [Español](README.es.md)

Este diretório contém layouts, espelhos e imagens de fabricação de placas do Robotinics.

O material inclui versões de placas de LEDs, servomotores, fonte e distribuição elétrica.

## Observação

Há múltiplas revisões e formatos. Esses arquivos devem ser tratados como acervo técnico e não automaticamente como versão de produção.

Sempre compare o PCB escolhido com o esquemático e a pinagem do firmware correspondente.
